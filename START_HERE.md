## 📱 How to Install as App (Mobile)

### On iPhone/iPad (Safari):
1. Open game in Safari
2. Play one game
3. Tap Share button (square with arrow)
4. Scroll down, tap "Add to Home Screen"
5. Tap "Add"
6. Icon appears on home screen!

### On Android (Chrome):
1. Open game in Chrome
2. Play one game
3. See "Install" prompt at bottom
4. Tap "Install"
5. Or: Menu → "Add to Home Screen"
6. Icon appears on home screen!

### On Desktop (Chrome/Edge):
1. Open game in Chrome or Edge
2. Look for install icon in address bar
3. Click it
4. Click "Install"
5. App opens in its own window!

## ❓ FAQ

### Q: What is PWA?
**A:** Progressive Web App - a web app that works like a native app. Users can "Add to Home Screen" and use it offline.

### Q: Do I need to publish to app stores?
**A:** No! PWA works directly from your website. No app store needed.

### Q: Will it work offline?
**A:** Yes! After first load, the game works completely offline.

## 🐛 Troubleshooting

### Game doesn't load:
- Check browser console for errors
- Clear cache and reload
- Try different browser

### Buttons don't appear:
- Check style.css is loaded
- Verify game.js has no errors
- Check browser console

### PWA won't install:
- Check manifest.json is correct
- Verify service worker registered
- Try different browser
- Check HTTPS (required for PWA)

### Sounds don't play:
- Check browser allows audio
- Click on page first (browser requirement)
- Check volume settings
